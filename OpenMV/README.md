# OpenMV 视觉模块代码

该版本为比赛时队友编写的钢球位置检测程序。

## 检测方案

- **传感器模式**：灰度 (`GRAYSCALE`)，分辨率 QVGA (320×240)
- **检测方法**：霍夫圆变换 (`find_circles`)，识别钢球圆形轮廓
- **ROI**：`(162, 0, 45, 240)`，聚焦管道区域
- **物理标定**：管道长度 162mm → 240 像素，约 0.675 mm/pixel

## 核心特性

### 卡尔曼滤波器
自实现的 `KalmanFilter1D` 类，融合测量值与运动模型：
- 正常跟踪时使用卡尔曼更新
- 短期丢失时纯预测（速度衰减系数 0.97）
- 恢复时支持 `soft_reset` 快速重新锁定
- 自适应残差阈值：球越靠近管道边缘，校验越严格

### 圆心稳定性校验
- 正常跟踪：检测到的圆心距卡尔曼预测 ≤60px
- 丢失恢复中：放宽至 ≤120px
- 溢出恢复校验：卡尔曼在极端位置时拒绝中段虚假圆心

### 丢失分级

| 连续丢失帧 | 发送格式         | 含义                 |
| ---------- | ---------------- | -------------------- |
| 1~100      | `X±ddddLOST\r\n` | Kalman 预测坐标      |
| 101~300    | `X±LOST\r\n`     | 只剩方向，无距离     |
| >300       | `lost\r\n`       | 彻底丢失，全状态重置 |

### 物理极限保护
球超出 ±75mm 时主动发送 `X±LOST\r\n`，不发送不可靠坐标。

### 自动曝光标定
上电 500ms 内自动调整曝光与增益后锁定，防运行中阈值漂移。

## 通信

USART 3, 115200bps, 8N1。帧格式见 [主 README](../README.md#8-串口通信协议)。

## 使用与标定

1. 将 `main.py` 拷贝到 OpenMV SD 卡
2. 根据现场光照微调 `CIRCLE_THRESHOLD`（默认 2150）
3. 验证 `R_MIN=7, R_MAX=8` 与实际钢球像素半径一致
4. 检查 `ROI` 与摄像头安装位置匹配
5. OpenMV IDE → Tools → Save open script → 上电自启
